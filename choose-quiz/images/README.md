# Vibe photos for the quiz

Drop the six vibe photos in **this folder**, named exactly as below. The quiz
picks them up automatically — no code changes needed. If a file is missing, that
card falls back to a coloured flower graphic (so it never looks broken).

| File to add        | Vibe / product        |
|--------------------|------------------------|
| `pink.jpg`         | Pink Vibe              |
| `carnival.jpg`     | Carnival Vibe          |
| `sunshine.jpg`     | Sunshine Vibe          |
| `mono.jpg`         | Mono Vibe              |
| `amethyst.jpg`     | Amethyst Vibe          |
| `spotlight.jpg`    | This Month's Spotlight |

Square images (the neon "…it's a vibe" product photos) work best. `.jpg`, `.png`
or `.webp` are all fine — just keep the filename the same (e.g. `pink.png` →
update the name in `index.html`, or simplest, save it as `pink.jpg`).

**Prefer to link the live shop images instead?** Send Claude the six image web
addresses (right-click each photo on the site → *Copy image address*) and the
`img:` values in `index.html` can point straight at them — they'll then update
automatically whenever you change a product photo.
